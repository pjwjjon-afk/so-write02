# 해결 방안 발표지 (실시간 공유 버전)

모둠 기기에서 쓴 내용이 몇 초 안에 전자칠판 화면에 나타나요. 파일을 주고받을 필요가 없어요.
저장은 Netlify에 내장된 저장 공간(Netlify Blobs)을 쓰기 때문에 따로 가입하거나 키를 넣을 곳이 없어요.

## 폴더 구성 (이 모양 그대로 올려요)
```
index.html                      화면
package.json                    서버 코드가 쓰는 부품 목록
netlify/functions/sheet.mjs     내용을 저장하고 돌려주는 서버 코드
README.md                       이 안내 (없어도 돼요)
```

## 1. 깃허브에 올리기
1. GitHub에서 새 저장소(Repository)를 만들어요.
2. **Add file → Upload files**를 누르고, 압축을 푼 폴더 안의 `index.html`, `package.json`, `netlify` 폴더를 끌어다 놓은 뒤 **Commit changes**를 눌러요.
3. 저장소에 `netlify/functions/sheet.mjs` 경로가 보이는지 확인해요.

## 2. 네틀리파이로 공유하기
1. Netlify에서 **Add new site → Import an existing project → GitHub**로 저장소를 골라요.
2. Build command와 Publish directory는 비워 두고 **Deploy**를 눌러요.
3. 배포가 끝나면 **Logs → Functions**에 `sheet`가 보이는지 확인해요.
4. 만들어진 주소(예: `https://○○○.netlify.app`)를 학생 기기와 전자칠판에서 열어요.

## 3. 수업에서 쓰는 순서
- **반 고르기**: 주소를 처음 열면 1반~12반 버튼이 나와요. 우리 반을 누르면 그 반의 화면이 열리고, 반마다 내용이 따로 저장돼요. 다음에 열면 마지막에 고른 반으로 바로 열려요. 다른 반으로 가려면 위쪽 **반 바꾸기**를 눌러요.
- **반 주소로 바로 들어가기**: 주소 끝에 `#3`처럼 반 번호를 붙이면(예: `https://○○○.netlify.app/#3`) 3반 화면이 바로 열려요. 반별로 이 주소를 알려 주면 학생들이 반을 고를 필요가 없어요.
- **모둠 기기**: 반을 고른 뒤 위쪽에서 우리 모둠 번호를 눌러 작성해요. 쓰는 즉시 저장돼요.
- **전자칠판**: 같은 주소를 열고 **발표 화면**을 눌러요. 아래 번호나 좌우 방향키로 모둠을 넘기면 그 모둠이 쓴 최신 내용이 보여요.
- **모둠 추가**: 위쪽 모둠 탭 끝의 **+ 모둠 추가**를 누르면 7모둠, 8모둠…이 생겨요(최대 12모둠). 모든 기기에 바로 같은 탭이 나타나요. 잘못 추가했으면 **마지막 모둠 빼기**를 눌러요.
- **초기화**: **이 모둠 초기화**는 지금 보고 있는 모둠만, **전체 초기화**는 지금 고른 반의 모든 모둠 내용을 비워요. 다른 반 내용은 그대로 있어요. 둘 다 한 번 더 물어본 뒤에 지워지고, 모둠 수는 그대로예요.
- 위쪽에 **실시간 연결됨**이 보이면 정상이에요. 붉은 글씨로 **연결 안 됨**이 보이면 그 기기에만 저장되고, 연결이 돌아오면 다시 보내요.

## 이미 올려 둔 것을 새 버전으로 바꾸려면
GitHub 저장소에서 **Add file → Upload files**를 누르고 `index.html`과 `netlify` 폴더를 다시 끌어다 놓은 뒤 **Commit changes**를 눌러요. 같은 이름의 파일은 새 것으로 바뀌고, Netlify가 1~2분 안에 자동으로 다시 배포해요. 저장된 모둠 내용은 그대로 남아요.

이전 버전으로 시험해서 저장해 둔 내용은 반 구분이 없어서 새 버전에는 나타나지 않아요. 수업 내용이 아니라면 그냥 두어도 돼요.

## 알아 둘 점
- 반영은 2~3초 걸려요. 지금 글을 쓰고 있는 칸은 다른 기기의 내용으로 바뀌지 않아요.
- 같은 모둠을 두 기기에서 동시에 고치면 나중에 고친 쪽이 남아요. 모둠당 1대만 쓰면 문제가 없어요.
- 주소를 아는 사람은 누구나 모든 모둠 내용을 보고 고칠 수 있어요. 수업 때만 주소를 알려 주세요.
- 다음 수업에 새로 시작하려면 칠판에서 **전체 초기화**를 눌러요.
- 글꼴은 인터넷에서 불러와요. 칠판이 인터넷에 연결돼 있어야 글씨체가 그대로 보여요.
